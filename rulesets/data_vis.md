

Static Charts

Pi chart: this is not a very useful chart despite how often it is used. If required, only do the top 6 categories, with different colors and dump the others into other. Make sure the "most important" category is at the 12 o'clock position. Convert numbers to percentages unless specifically told otherwise. 

Histograms: 
Ask before omitting values because you believe they are outliers. EMS data frequently has verified, 1+ hour response times. Skews should be noted. 

Tables:
If displaying a table, allow for a toggle over to a table of percentages. The last rob should be Total: 100% 

Line charts:
Make these clean and simple. 

Horizontal Bar Charts:
Use horizontal bar charts for categorical data, e.g. causes of fire. Make the rankings descending, 1st highest result.  

Pictograms:
Should be simple, black stroke
